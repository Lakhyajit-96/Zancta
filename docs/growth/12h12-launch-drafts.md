## Product Hunt

**Tagline:** PDF and image tools that run in your browser.

**One line:** Merge, compress, convert, and OCR files locally — ZANCTA does not upload your documents for processing.

**Full description (draft):**
ZANCTA is a small suite of PDF and image tools that process files in the tab after the page loads. Merge, split, compress, convert, resize, strip EXIF, extract embedded PDF text, and run English OCR without sending the file to a conversion API. Additional OCR languages and scanned PDF OCR are Local OCR Power on Premium; checkout is not live yet. Limits are shown on each tool. OCR is not human-level.

**Maker story (draft):**
I did not want contracts and IDs sitting on a converter’s disk. The engineering choice is pdf-lib, PDF.js, and Tesseract.js in Web Workers, with language packs loaded only when selected.

**Launch-day FAQ (draft):**
- Are files uploaded? Not for implemented local tools.
- Is OCR perfect? No.
- Is Premium purchasable today? Only when checkout is enabled; the site says so.
- Ads? Not enabled.

**Screenshots needed:** homepage, Merge PDF completed state, Image OCR workspace, pricing with checkout not available.
